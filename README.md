# 今天吃什么 · 可运行原型

一个可公开部署、无需安装依赖的响应式网页应用，模拟“按家中食材与饮食偏好生成菜单”的核心流程。部署后，任何人都可通过链接使用，也可在手机浏览器中安装到桌面。

## 在线使用（推荐）

访问部署后的网页链接即可使用，不需要下载或安装。若浏览器显示“安装应用”或“添加到主屏幕”，可选择它把网页添加为手机或电脑上的应用图标。

## 下载后本地使用

从 GitHub 下载 ZIP 并解压后，请双击 **`双击这里打开应用.html`**，或用浏览器打开 `index.html`。

**不要双击 `app.js`**：它是网页内部的逻辑文件，双击会被 Windows Script Host 当作脚本运行，从而出现 JavaScript 语法错误。

为启用离线缓存和“安装到设备”，请在此目录启动本地静态服务器，例如：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 公开发布

最省事的方式是使用 Netlify：登录后将整个 `today-eat` 文件夹拖入 Netlify 的 Deploy 页面，即可获得一个可公开访问的 HTTPS 链接。仓库中已包含 `netlify.toml`，无需构建命令。

也可将这个目录上传到任意静态托管服务（GitHub Pages、Cloudflare Pages、Vercel 等）；部署目录就是当前目录。

## 已实现

- 食材搜索、常用食材快捷添加与移除
- 菜系、人数、饮食目标选择
- 基于已有食材和偏好的菜单排序与“换一批”
- 菜谱详情弹窗、营养汇总与缺货清单
- 本地保存食材与饮食目标，刷新页面不会丢失
- PWA 离线缓存与安装到手机桌面
- 下载 ZIP 后的本地启动入口，避免误打开脚本文件
